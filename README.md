# BDtheme 2.0 — Blogger content + GitHub Pages website

এই সংস্করণে Blogger থাকবে কনটেন্ট ম্যানেজমেন্ট/অ্যাডমিন হিসেবে। GitHub Actions Blogger-এর পাবলিক পোস্ট ফিড পড়ে সম্পূর্ণ static website তৈরি করে GitHub Pages-এ প্রকাশ করবে। পোস্টের পেজ, ক্যাটাগরি পেজ, SEO metadata, sitemap ও robots.txt build-এর সময় তৈরি হয়।

## ১. Blogger সেটিং
1. Blogger → Settings → Site feed → Allow blog feed: **Full** (অন্তত পোস্টের full content প্রকাশিত হতে হবে)।
2. ব্লগ Public থাকতে হবে; private feed এই workflow পড়তে পারবে না।
3. Blogger-এ স্বাভাবিকভাবে পোস্ট লিখুন, ছবি দিন, label দিন, Publish করুন।
4. পোস্টে পণ্যের দাম লিখতে পারেন `[price: 1200]` অথবা `Price: 1200` label। Collection label `config.js`-এ হুবহু মিলিয়ে দিন।

## ২. GitHub Pages চালু
1. এই ZIP-এর সব ফাইল repository-র root-এ upload করুন (ভেতরের ফোল্ডারসহ)।
2. `config.js` খুলে অন্তত `blogUrl`, `siteName`, `siteUrl`, `basePath`, WhatsApp নম্বর, currency ও collection/category labels ঠিক করুন।
   - User/Org site হলে `basePath: ""` এবং `siteUrl: "https://USERNAME.github.io"`।
   - Project site হলে `basePath: "/REPOSITORY-NAME"` এবং `siteUrl: "https://USERNAME.github.io"`।
3. GitHub → Settings → Pages → **GitHub Actions** নির্বাচন করুন।
4. Actions tab-এ `Build Blogger site and deploy to GitHub Pages` workflow চালু/রান করুন। `main` branch-এ push হলে, manual run করলে এবং প্রতি ঘণ্টায় workflow Blogger থেকে নতুন পোস্ট sync করবে।
5. Actions run সফল হলে Pages URL-এ সাইট দেখুন। প্রথমবার deploy হতে কয়েক মিনিট লাগতে পারে।

## ৩. রিভিউ ও রেটিং (Supabase)
রিভিউ ডেটা GitHub Pages-এ রাখা যায় না, তাই Supabase ব্যবহার করা হয়েছে। এটি ঐচ্ছিক backend; Supabase সেটআপ না করলে রিভিউ ফর্মে setup notice দেখাবে।

1. Supabase project তৈরি করুন → SQL Editor-এ নিচের SQL রান করুন:

```sql
create table if not exists public.reviews (
  id bigint generated by default as identity primary key,
  post_id text not null,
  name text not null check (char_length(name) between 1 and 70),
  rating int not null check (rating between 1 and 5),
  review text not null check (char_length(review) between 1 and 1500),
  approved boolean not null default false,
  created_at timestamptz not null default now()
);
alter table public.reviews enable row level security;
create policy "public can read approved reviews" on public.reviews
  for select to anon using (approved = true);
create policy "public can submit pending reviews" on public.reviews
  for insert to anon with check (approved = false);
```

2. Supabase → Project Settings → API থেকে Project URL এবং anon/public key নিন। `config.js`-এর `reviews.supabaseUrl` ও `reviews.anonKey`-এ বসান। **কখনো service_role key frontend-এ দেবেন না।**
3. Supabase Table Editor → `reviews`-এ নতুন জমা রিভিউ `approved=false` থাকবে। যাচাই করে `approved=true` করুন; তখন পোস্টে প্রকাশ পাবে।
4. Spam protection/Rate limit চালু করতে চাইলে Supabase Edge Function বা CAPTCHA যোগ করুন; public anon insert endpoint-এ অতিরিক্ত abuse protection প্রয়োজন।

## ৪. SEO ও সাইট ফিচার
- Build-time প্রতিটি পোস্টের নিজস্ব HTML URL: `/posts/<slug>/`।
- প্রতিটি পোস্টে title, description, canonical URL, Open Graph, Article JSON-LD structured data এবং publish/modified date তৈরি হয়।
- ক্যাটাগরি/label অনুযায়ী static category pages, `sitemap.xml`, `robots.txt` ও `atom.xml` তৈরি হয়।
- Home page-এ Blogger feed থেকে live content; static JSON snapshot `data/posts.json`-এ build হয়।
- Original BDtheme XML, CSS reference, product price parsing, cart ও WhatsApp checkout রাখা হয়েছে।
- Browser-side cart স্থানীয় storage-এ থাকে; WhatsApp order link খুলে। এটি payment gateway বা server-side order database নয়।

## ৫. গুরুত্বপূর্ণ সীমাবদ্ধতা
- GitHub Pages static hosting। Blogger-এর Layout Editor, native Blogger comment iframe, server-side checkout/payment, member login এবং server-side search সরাসরি GitHub Pages-এ চলে না।
- SEO-friendly HTML ও sitemap তৈরি করতে GitHub Actions workflow সফলভাবে চলা আবশ্যক। নতুন পোস্ট sync schedule hourly; তাৎক্ষণিক sync চাইলে Actions থেকে workflow manual run করুন।
- `siteUrl` ও `basePath` সঠিক না হলে canonical URL/sitemap ভুল হবে।
- Blogger feed public/full content না দিলে বা Blogger feed access বন্ধ থাকলে build ব্যর্থ হতে পারে।
- XML-এর প্রতিটি Blogger widget/setting GitHub-এ ১:১ স্থানান্তর করা যায় না; source XML `original-blogger-theme.xml` হিসেবে সংরক্ষিত আছে।

## Files
- `index.html` — storefront/homepage
- `post.html` — fallback detail route
- `scripts/build.mjs` — Blogger feed থেকে static post/category pages, JSON, sitemap ও robots তৈরি
- `.github/workflows/deploy.yml` — scheduled build + GitHub Pages deploy
- `assets/js/reviews.js` — Supabase review integration
- `original-blogger-theme.xml` — আপনার দেওয়া মূল BDtheme XML
